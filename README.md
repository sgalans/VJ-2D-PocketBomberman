# Pocket Bomberman

Versió de **Pocket Bomberman** de Game Boy Color desenvolupada per Sergi Galán i Oriol València per a l'assignatura de Videojocs de la **FIB–UPC**, a partir del framework de laboratori *02-Bubble*.

És un joc de plataformes 2D per a un sol jugador: cal eliminar tots els enemics i arribar a la porta de sortida abans que s'acabi el temps. Les bombes queden suspeses a l'aire i serveixen tant per atacar com per crear plataformes amb què arribar a zones elevades.

El joc inclou **cinc nivells i un boss final**, enemics amb comportaments diferents, arbustos destructibles, objectes de millora, portes amb clau, plataformes temporals i trampolins activats amb explosions.

Desenvolupat en **C++ i OpenGL**, amb GLFW, GLEW, GLM, SOIL i FreeType, per a Windows.
